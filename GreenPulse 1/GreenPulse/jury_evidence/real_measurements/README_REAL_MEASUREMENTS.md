# GreenPulse Real Measurement Kit

This directory is for REAL experimental measurements only.

## Rules

1. Do not enter synthetic, guessed or presentation-only numbers.
2. Leave unavailable values blank.
3. Keep raw measurements unchanged.
4. Record device/model/run identifiers.
5. Preserve timestamps and units.
6. Estimated sustainability values must remain explicitly distinguishable from measured values.
